# 🍽️ Bains Restaurant Website

A responsive restaurant website developed using HTML5 and CSS3. This project was created to demonstrate fundamental web development skills, including page structure, navigation, responsive layouts, image integration, and user interface design.

---

## 🌐 Live Website

https://innabains.github.io/

---

## 📖 Project Overview

Bains Restaurant is a static website designed for a fictional restaurant business.

The website provides:

- Homepage
- Restaurant introduction
- Menu promotions
- Contact form
- Navigation menu
- Responsive page layout
- Image-based content presentation

The project demonstrates core front-end development concepts and user interface design principles.
